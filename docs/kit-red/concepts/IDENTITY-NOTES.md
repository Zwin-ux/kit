# Refined identity and daily session

The latest direction is Kit as a conversational coding tool with its own fox and four job identities. The setup illustration is now an asset study; daily-session.png is the main product concept. See ../SESSION-DESIGN.md.

Smaller pointed fox, tapered muzzle and cream cheeks replace the rejected wide head. Four related silhouettes replace punctuation placeholders: browser window, stacked layers, server drawers, connected model nodes. In conversation, show only effective kit context. Show the four choices when the picker is requested.

These are generated pixel-art concepts, not production sprites or ASCII. Before shipping, redraw on an explicit grid and inspect at native size. Use verified terminal graphics support where available; text-only terminals retain full names and compact fallback marks. Do not depend on emoji fonts, Nerd Fonts or recognition of icons. Verify baseline, width, scroll cleanup and resize behavior. No new runtime asset downloads or animation system.

Both images use the built-in image-generation tool. Exact prompts are role-icons-refined.prompt.txt and daily-session.prompt.txt. The session reuses the refined identity as reference. Read/tool output is fixture text. The /kit session hint is proposed, not an installed command. Generated texture is not intended for implementation: the real terminal background stays flat. The icon-study row spacing is illustrative and must not force a taller production picker.
