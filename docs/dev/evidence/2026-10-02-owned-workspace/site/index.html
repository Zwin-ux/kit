Kit — your owned coding workspace

Dispatch coding agents in parallel, watch them in one control room, and land only work that has been proven.

Before you start

This is a local build of Kit running from your own machine. There is no hosted service and no download on this page.

You sign in through the provider's official CLI (Claude Code or Codex). Your credentials stay with that CLI — Kit never asks for, stores, or sees them.

Your provider's plan and usage limits apply to every agent Kit dispatches.

One workspace, four roles

  • Frontend

    UI, layout, accessibility and interaction work.

  • Backend

    APIs, data, services and the engine underneath.

  • Security

    Scope, secrets hygiene and hardening review.

  • Product

    Specs, priorities and the call on what ships.

Get started

Run these in Terminal.

  1. Connect your provider

    Kit hands off to the provider's official CLI to sign in. Credentials stay with it.

    kit connect claude

  2. Open the control room

    Launch Kit to see every run in one table.

    kit

  3. Dispatch a run

    Give an agent a task in your project.

    kit run "add a test for X" --agent claude

Nothing ships unproven

An agent finishing is not a result. A real result must pass your project's checks and be reviewed by you. Only then does kit land create a branch with the change — Kit does not merge or push for you.
