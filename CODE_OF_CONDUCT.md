# Code of Conduct

Kit adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for every space the project runs: issues, pull requests, discussions and reviews.

In short: be kind and constructive, assume good faith, critique code and ideas rather than people, and
make room for newcomers. Harassment, insults, and personal or political attacks are not accepted.

## Reporting

Report conduct problems privately to the owner, Mazen Zwin, through
[GitHub's private vulnerability form](https://github.com/Zwin-ux/kit/security/advisories/new) with the
title starting "Conduct:" (if that form is not available, open an issue titled "Conduct contact request"
with no details, and the owner will reply with a private channel). Reports are
kept confidential. The owner decides on a response following the Contributor Covenant's enforcement
guidelines (correction, warning, temporary ban, permanent ban).
